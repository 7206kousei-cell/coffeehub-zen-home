

# CoffeeHub — Mobile Home Screen

A single-screen Japanese minimalist coffee brewing tracker with a premium specialty coffee aesthetic.

## Screen Sections (Top → Bottom)

### 1. App Bar
- Left: line-art coffee drip icon + "CoffeeHub" wordmark
- Center: current date in Japanese format (2026年2月13日 金)
- Right: circular avatar with red notification dot

### 2. Hero / Caffeine Dashboard
- Large greeting "おはよう" in elegant typography
- Subtext "今日の摂取カフェイン"
- Oversized caffeine number (142mg) in deep coffee brown
- Safety margin note "安全摂取目安まであと258mg"

### 3. Quick Action Cards (4-up horizontal row)
- Equal-sized rounded cards with subtle shadows
- Log Brew (primary accent color), Last Brew, Beans, Stats
- Each with icon + short label

### 4. Recent Brews (horizontal scroll)
- Cards at ~70% screen width, horizontally scrollable
- Each card: bean image placeholder, bean name, roaster, star rating, brew method icon

### 5. Daily Insight Card
- Soft-bordered card with light background
- Title: 今日のひとこと
- Tip text: "この豆は92℃で最も高評価が出ています"

## Design System
- Background: #FAFAF8 (warm off-white)
- Primary: #5F4035 (deep coffee brown)
- Accent: #E0785A (warm orange)
- Border radius: 16–24px throughout
- Generous whitespace and padding
- Inter + Noto Sans JP font pairing
- Aesthetic: MUJI × Blue Bottle Coffee — clean, premium, minimal
